# Algoritmo de Dijkstra en Rust

## Descripción

Este proyecto implementa el algoritmo de Dijkstra en el lenguaje Rust.  
El algoritmo permite encontrar las distancias mínimas desde un nodo origen hacia todos los demás nodos de un grafo ponderado sin pesos negativos.

## Requisitos

- Tener Rust instalado.
- Tener Cargo instalado.

Para verificar la instalación:

```bash
rustc --version
cargo --version

```
Correr en la terminal:
rustc distancias.rs

Luego:
.\distancias.exe
